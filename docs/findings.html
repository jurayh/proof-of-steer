What the sessions say

Findings, not claims.

Every finding below was measured on a named corpus, and every number is tied to the report that measured it. Nothing on this page is a new result. Where a number is a presence signal or a floor rather than a dose, it says so.

Most interactive turns move no files

52.8% of human turns are procedural

In the trace-commons Claude Code sessions, 207 of 392 human turns are procedural: no file operation followed the prompt at all. Approvals, answers, and discussion are real interaction, but they leave no lines. A raw turn count therefore overstates steering before any other correction.

Corpus: trace-commons, 28 Claude Code sessions, 392 segments. Source: impact-spike/REPORT.md, per-class distributions table.

The headline field detects presence, not dose

At SWE-chat scale, the post-first-prompt share separates one-prompt work from steered work, and then saturates. It is a steering-presence detector, not a steering-dose meter, and must not be read as a score.

0.0 median, one-prompt sessions

0.754 median, continued sessions with no pushback turns

0.967 median, sessions with any pushback turn

Within pushback sessions, more pushback does not read higher: the high-pushback group sits below the low-pushback group. The presence boundary separates; dose within steered sessions does not.

Corpus: SWE-chat (SALT-NLP), 17,968 sessions; the headline-field analysis in section 6 uses the sessions carrying prompt attributions, with the pushback grouping over the multi-segment sessions that have both labels and attributions (330 no-pushback, 1,912 any-pushback). Source: swe-chat/VALIDATION.md, section 6. The same conclusion is stated in the Evidence section of site/index.html.

At decision points, users usually take the marked recommendation, and sometimes refuse the question

70.7% followed, of questions where a recommendation was marked

When an agent marks a recommended option, users take it about seven times in ten. That rate is read only against the marked subset: agents mark inconsistently, so the denominator travels with the number. In SWE-chat, a recommendation was marked on only 4,327 of 10,739 questions (40.3%). A listed pick on an unmarked question is not evidence about recommendations.

6.8% of SWE-chat decision calls were rejected as posed

587 of 8,597 Claude Code decision calls in SWE-chat were refused by the user as posed. Rejected calls are counted separately and never folded into the answered-question classes.

Corpus: SWE-chat, Claude Code only, 12,418 sessions and 8,597 decision calls (of 17,968 SWE-chat sessions across all agents); pooled marked subset 4,328 questions. Source: decision-spike/REPORT.md, base rates and the marked subset.

The steering mark under-claims, and says so

82 of 271 (30.3%) genuinely steered sessions read One-shot

After the 0.1.4 op-collection fix, 82 of 271 genuinely steered code sessions still read One-shot. Every observed case was a coverage failure, not a boundary error: the steering happened where the measurement could not see it, in edits to files an unseeded reconstruction had no base for. The receipt prints its coverage, including whether every Edit and Write op in the transcript was collected, so a reader can price a One-shot mark by how much of the session could be measured at all.

The mark almost never over-claims in the other direction: one-prompt controls read above One-shot 3 times in 257, each a two-turn session whose second turn did genuine work.

Corpus: false one-shot validation, pooled code mode, 271 genuinely steered sessions (21 trace-commons interactive Claude Code, 250 sampled SWE-chat Claude Code) and 257 controls. Source: false-oneshot-validation/ADDENDUM.md (v0.1.4 re-run), headline table and cause split; original run in false-oneshot-validation/REPORT.md.

For documents, the map is precise and the headline is a floor

88.3% sentence-level agreement with keystroke-level ground truth

Doc mode's per-part labels, which parts of a document are unchanged from its first version, agree with keystroke-level ground truth on 88.3% of sentences. The headline percentage, by contrast, is a floor on the untouched share, not a dose estimate: it understates the untouched share and moves with revision granularity, so it must be read as at least that much surviving verbatim, never as how much steering happened.

Corpus: CoAuthor, 1,447 writing sessions (Lee et al., CHI 2022). Source: coauthor/VALIDATION-coauthor.md, sections 4.2 and 5.

How to read this page

Three rules travel with every number here. Presence is not dose: a field that separates steered from one-prompt work does not measure how much the steering was worth. A floor is not an estimate: a doc headline says at least that much survived, not exactly that much. And coverage qualifies the mark: a One-shot mark on a thin receipt is a receipt declining to testify, not a judgment on the work.
