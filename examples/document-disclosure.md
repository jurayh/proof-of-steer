# Document disclosure snippet

The document equivalent of the pull request template snippet. A short,
paste-ready disclosure block an author puts at the top of a document so a
reader gets the steering picture without running a CLI. It is generated
from a document receipt, never hand-filled, so its numbers cannot drift
from the receipt:

```
steerprint doc.receipt.json --disclosure -o disclosure.md
```

Sections are grouped, not listed as a full table: unchanged since the
first version, arrived in later revisions, reshaped after first appearing.
The full per-section map stays in the STEERING.md that travels with the
receipt. When the history is truncated, the History line says so, and the
shares are relative to the first available revision. The headline
percentage is a floor on the untouched share, never a dose, and the block
is descriptive evidence, never a certified grade.

Copy the template below and fill it with the generator, or paste a
generated block as-is:

---

## Steering disclosure

This document was written with an AI agent, and its revision history carries
a steering receipt. The receipt reports what observably happened across
revisions: how much of the final text survives verbatim from the first
version, which sections arrived later, and which sections were reshaped
after they first appeared.

- Steering mark: <!-- for example: Closely steered, 3 revisions -->
- First version to final: <!-- for example: at least 36.0% of the final text survives verbatim from the first version -->
- Sections unchanged since the first version: <!-- list them -->
- Sections that arrived in later revisions: <!-- list them with the revision that introduced each -->
- Sections reshaped after first appearing: <!-- list them, or the receipt's own count when it differs from the sections that gained lines -->
- History: <!-- complete, or truncated at the first available revision -->
- Full section map: see the STEERING.md that travels with this receipt.

Generated from the document receipt with `steerprint <receipt.json> --disclosure`.
The receipt carries counts and categories only, never prompt text, and the
revisions never leave your machine. Descriptive evidence, never a certified
grade. Material rejected or dismissed before it ever entered a revision is
invisible to this receipt, so what it shows is a lower bound on interaction.

Delete this section if no agent was involved.

---

## Filled sample: the Personal-Guard findings draft

Generated by the render path itself from
`examples/doc-steered-findings-draft.receipt.json`. The suite test
`tests/test_disclosure.py` asserts this sample equals the renderer's output
for that receipt exactly, so the two cannot drift apart. Note the reshaped
line: the mark counts 1 of 18 sections reshaped, while 2 sections gained
lines later. The mark's rule requires the section heading to survive
unchanged, and the title section's heading text changed between versions,
so it is not counted as reshaped even though it gained a line. The block
says so instead of claiming 2.
